- **วิดีโอที่แปลแล้ว**
- **คำบรรยายภาษาปลายทาง** (SRT)
- **คำบรรยาย SRT แบบสองภาษา**

<a name="what-is-video-translate-skill"></a>
## Video Translate Skill คืออะไร

Video Translate Skill เป็น**เครื่องมือแปลวิดีโอด้วย AI** แบบอัตโนมัติสำหรับครีเอเตอร์ นักการศึกษา และทีมงานที่ต้องการเนื้อหาวิดีโอหลายภาษา แทนที่จะต้องถอดเสียง แปล ทำคำบรรยาย อัดเสียงพากย์ และตัดต่อด้วยมือ คุณเพียงแค่ระบุไฟล์ MP4 ในเครื่อง แล้ว Skill จะจัดการทั้งเวิร์กโฟลว์ ได้แก่ การรู้จำเสียงพูด การแปล การจับเวลาคำบรรยาย การพากย์ด้วย TTS และการรวมเสียง

<a name="features"></a>
## ความสามารถ

- **การแปลวิดีโอด้วย AI** – แปลเนื้อหาที่พูดจากภาษาหนึ่งเป็นอีกภาษาหนึ่ง
- **การพากย์เสียงต้นฉบับ** – ขับเคลื่อนโดย SoulDub AI เพื่อรักษาลักษณะเสียงของนักพูด
- **การสร้างคำบรรยายพร้อมเวลา** – ผลิตคำบรรยาย SRT ที่แม่นยำและตรงกับเสียงพูด
- **คำบรรยาย SRT แบบสองภาษา** – แสดงภาษาต้นฉบับและภาษาปลายทางพร้อมกัน เหมาะสำหรับการเรียนรู้ภาษาและการตรวจทาน
- **การพากย์ด้วย TTS** – สร้างเสียงพูดที่เป็นธรรมชาติในภาษาปลายทาง
- **การรวมเสียงอัตโนมัติ** – แทนที่แทร็กเสียงต้นฉบับด้วยแทร็กที่พากย์แล้ว
- **รองรับไฟล์ MP4 ในเครื่อง** – ทำงานโดยตรงกับไฟล์ MP4 บนเครื่องของคุณ

<a name="installation"></a>
## การติดตั้ง

ติดตั้ง Skill ให้กับ Agent AI ของคุณด้วยคำสั่งเดียว:

```bash
npx skills add jiabaogithub/souldub-skills --skill souldub-video-translate
```

<a name="requirements"></a>
## ข้อกำหนด

- Python 3.11 หรือใหม่กว่า
- [`uv`](https://docs.astral.sh/uv/)
- การเชื่อมต่ออินเทอร์เน็ต
- คีย์ API ของ SoulDub
- สิทธิ์อ่านวิดีโอต้นฉบับและสิทธิ์เขียนลงในโฟลเดอร์ผลลัพธ์

### ตั้งค่าคีย์ API ของคุณ

ใช้วิธีใดวิธีหนึ่ง:

```yaml
# ~/.souldub/souldub.config.yaml
souldub_api_key: "YOUR_API_KEY"
```

```bash
export SOULDUB_API_KEY="YOUR_API_KEY"
```

ตรวจสอบการยืนยันตัวตน:

```bash
uv run scripts/video_translation.py auth status
```

<a name="usage"></a>
## การใช้งาน

หลังจากติดตั้งแล้ว เพียงบอก **เส้นทางวิดีโอ** และ**ภาษาปลายทาง**แก่ Agent ตัวอย่างเช่น:

> แปล `/path/to/video.mp4` เป็นภาษาอังกฤษด้วยการพากย์เสียงต้นฉบับ

Agent จะถามข้อมูลที่ขาดหายไป เริ่มงาน รายงานความคืบหน้า และส่งคืนเส้นทางของไฟล์ผลลัพธ์

<a name="how-it-works"></a>
## วิธีการทำงาน

1. **อินพุต** – ระบุวิดีโอ MP4 ในเครื่องและเลือกภาษาปลายทาง
2. **แปล** – รู้จำเสียงพูดและแปลเป็นภาษาปลายทาง
3. **คำบรรยาย** – สร้างคำบรรยาย SRT พร้อมเวลา รวมถึงเวอร์ชันสองภาษา
4. **พากย์** – TTS สร้างเสียงพากย์ โดยใช้เสียงต้นฉบับผ่าน SoulDub AI
5. **รวม** – แทร็กเสียงใหม่ถูกรวมกลับเข้าไปในวิดีโอ
6. **ดาวน์โหลด** – รับวิดีโอที่แปลแล้วและไฟล์คำบรรยาย

<a name="output-files"></a>
## ไฟล์ผลลัพธ์

| ไฟล์ | คำอธิบาย |
| --- | --- |
| วิดีโอที่แปลแล้ว (MP4) | วิดีโอที่มีแทร็กเสียงพากย์ในภาษาปลายทาง |
| SRT ภาษาปลายทาง | คำบรรยายพร้อมเวลาในภาษาที่แปลแล้ว |
| SRT แบบสองภาษา | คำบรรยายที่แสดงทั้งข้อความต้นฉบับและข้อความแปล |

โดยค่าเริ่มต้น ไฟล์จะถูกบันทึกเป็น `result.mp4`, `translated.srt` และ `bilingual.srt` ในโฟลเดอร์ `souldub_outputs/` ถัดจากวิดีโอต้นฉบับ

<a name="configuration--privacy"></a>
## การกำหนดค่าและความเป็นส่วนตัว

- ไฟล์ Skill ที่ติดตั้งแล้วจะถือว่าเป็นแบบอ่านอย่างเดียว สถานะการทำงานจะถูกเก็บไว้ในไดเรกทอรีสถานะผู้ใช้ของแพลตฟอร์ม
- ผลลัพธ์จะถูกเขียนไปยัง `souldub_outputs/` ถัดจากวิดีโอต้นฉบับโดยค่าเริ่มต้น
- Skill ไม่เก็บคีย์ API, URL อัปโหลดแบบพรีไซน์, URL เกตเวย์สื่อ หรือพารามิเตอร์ชั่วคราวแบบลงนาม

<a name="use-cases"></a>
## กรณีการใช้งาน

- การโลคัลไลซ์วิดีโอสำหรับการเปิดตัวผลิตภัณฑ์และการตลาดทั่วโลก
- การแปลคอร์สเรียนและบทเรียนสำหรับการศึกษาออนไลน์
- การกระจายเนื้อหาข้ามภูมิภาคบน YouTube, TikTok และอื่น ๆ
- คำบรรยายหลายภาษาสำหรับการเข้าถึงและการเรียนรู้ภาษา
